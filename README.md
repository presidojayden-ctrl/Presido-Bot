# Presido Bot

A WhatsApp bot built with Node.js and Baileys.

## Setup

```bash
npm install
npm start
```

On first start, scan the QR code using WhatsApp > Linked devices.

## Commands

- `!ping` — Check that the bot is online.
- `!menu` — Show available commands.
- `!help` — Show help.

WhatsApp session credentials are stored in `auth_info_baileys/` and excluded from Git.
